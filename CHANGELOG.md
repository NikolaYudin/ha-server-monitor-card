# Changelog

## [1.0.0] — 2026-09-28

### Добавлено
- Мониторинг 4 серверов: Hypervisor (Proxmox), NAS, Home Assistant OS, Desktop VM
- Кнопки управления VM в шапке (Start/Stop/Reboot/Shutdown) с подтверждениями
- Фирменные цвета брендов: Proxmox 🟠, NAS 🔵, HA 🔷, Desktop 🟣
- Графики CPU, RAM, Network I/O, Storage с 24-часовой историей
- Стиль Windows 11: скругления 8px, Segoe UI Variable, полупрозрачные кнопки
- Склеенный заголовок+панель кнопок как единая карточка
- Адаптив к светлой и тёмной теме через CSS-переменные
- Responsive layout: 4 колонки на десктопе, стек на мобильных
- Универсальные имена entity_id: пользователь легко подставит свои сенсоры
